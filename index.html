Sway Lab swaylab.ai
上面这些是在哪做出来的。六个 agent 各自干活，每天 09:30 出一份《AI 动态日报》，每个项目都有一篇讲来龙去脉的笔记。首页可以直接和接管了这个站的 agent 对话。
swaylab.ai →
大师.skill master-skill
输入一个行业，自动跑六轨调研，提炼成一个可运行的行业 Master OS skill。装到任意 agent，它就进入「这一行资深人」的模式。已索引数十个行业，点开就能和大师对话。
master-skill.org →
私教.skill sijiao-skill
把方向反过来：不是让 AI 替你成为专家，而是蒸出一个记得你学到哪、按你水平出题批改、替你排间隔复习的私教，把你自己训练成会的人。
查看官网 →
断舍离.skill danshari-skill
整个生态都在做加法，这个做减法：审计你装的全部 skill，把模型已经会的、harness 已自带的、MCP 已接管的归档移除。永不 rm，一条命令可恢复。
查看官网 →
humanize-chinese 中文 AI 文本
检测中文文本有多像 AI 写的，再改写到读着像人写的。附六个文体的实测：这个分数在科普短文上还好用，在长篇博客上方向是反的。纯 Python 离线。
查看官网 →
孙割.skill sunge-skill
把孙宇晨蒸成大脑、写作、决策三样。学《我的女友景甜》那种冷小作文的文风写作，也能把故事里的关键决策抠出来。孙学 · 孙宇晨文风。
